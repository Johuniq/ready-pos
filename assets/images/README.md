# Plugin Banner Images

This directory should contain banner images for the WordPress plugin listing page.

## Required Images:

1. **banner-1544x500.png** - High resolution banner (1544x500px)
2. **banner-772x250.png** - Low resolution banner (772x250px)

## Design Guidelines:

- Use your brand colors and logo
- Include the plugin name "Ready POS"
- Keep text minimal and readable
- Use high-quality graphics
- Ensure the design looks good on both light and dark backgrounds

## Fallback:

If these images are not present, WordPress will use the default plugin icon/banner.
